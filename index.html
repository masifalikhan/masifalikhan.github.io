Research

A Contribution-Aware Aggregation in Federated Learning

FedAvg treats every client the same, so weak or harmful updates drag the global model down. My framework measures each client's utility and sets aggregation weights from it.

Results

On MNIST and Fashion-MNIST, the framework converged more smoothly and generalized better than four strong baselines:

FedAvgFedProxSFedAvgGreedyFed

Key ingredients: FedProx-style proximal training, FW-Shapley contribution estimation and Beta-Shapley coalition sampling.

Local training

Proximal term keeps client drift in check.

Coalition sampling

Beta-Shapley picks client coalitions efficiently.

Contribution score

FW-Shapley estimates each client's utility.

Dynamic weights

Useful updates amplified, harmful ones suppressed.

Global update

Server aggregates and broadcasts the new model.
